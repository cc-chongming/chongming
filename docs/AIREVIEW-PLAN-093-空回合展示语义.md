# AIREVIEW-PLAN-093 空回合展示语义：无内容回合不显示“已完成”

状态：✅ 完成

## 背景
议题3 的 R2 零回合却显示“已完成”、共识度仍 50%（复用 R1 的 claim 计算），误导。
机制合理（082 给二轮机会、076 静默关题），坏在展示语义。

## 方案
- [#1] ReviewLiveView 增 hasRoundTurns(topic, round)：topic.turns 或该议题答辩合成回合含 round 匹配。
- [#2] 回合选项卡文案：无回合且议题终态→“无内容”；无回合且进行中→“进行中”；有回合→“已完成/进行中”现状。
- [#3] selectedRound 默认/切换议题时回落“有回合的最大回合”（全空则 1），不默认选中空回合。
- [#4] 中央共识度：选中回合无回合且议题终态时显示“本轮无内容”替代百分比。
