# AIREVIEW-PLAN-053 评审规划页移除模板计划卡

> **状态**: ✅ 全部完成
> **创建日期**: 2026-08-28
> **目标**: 评审规划页不再展示启动模板计划（v1 样板），只保留协调者真实计划修订卡；无修订时不显示该区块。

## 背景

- 用户批注：“评审计划 v1 到底有啥具体作用，没用就删除吧”。
- 取证：卡片渲染 `planCards`（PLAN_CREATED + PLAN_REVISED 事件）。PLAN_CREATED 的任务清单来自启动命令的 `publicTasks`（RequirementReviewLaunchService/StartRequest 链路），为固定模板（“核对需求范围、验收标准与实现风险”），所有评审相同、零信息量；PLAN_REVISED 来自协调者写 plans/PLAN.md 的提升（PLAN-036 机制），含真实版本/任务清单/修订原因，有价值。
- 结论：删除模板卡展示，保留修订卡；无修订时区块隐藏（`v-if="planCards.length"` 既有行为）。

## 分段方案

### 段 1：过滤模板计划 + 空态文案更新

**涉及文件**：修改 `frontend/src/views/ReviewLiveView.vue`

**关键实现细节**：
- `planCards` 计算属性过滤条件由 `PLAN_CREATED || PLAN_REVISED` 改为仅 `PLAN_REVISED`；
- `streamEmpty` director 分支文案中“评审计划与任务清单见下方计划卡”的表述更新为修订卡口径（协调者修订计划后才显示修订卡，含版本/任务清单/修订原因）；
- 卡片渲染模板（计划修订 vN / 任务列表 / 修订原因）不动。

## 风险与应对

- **风险**：用户想看“评审范围”入口 → 协调者真实计划经修订卡呈现，信息量更高；初始模板无展示价值。
- **风险**：协调者从不写 PLAN.md 时区块恒隐 → 预期行为，不占界面；如后续需要可再立计划增强计划模式触达。
