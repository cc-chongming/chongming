- REST 客户端集中放在 `api/review-api.js`，所有请求经统一的 `request()` 包装并抛出带 status/errorCode/traceId/body 的 `ReviewApiError`，调用方用 `optional()` 模式处理 404 降级。
- SSE 订阅采用工厂函数返回 `{ close() }` 句柄，内部维护 `cursor` 游标并通过 `afterSequence` 参数实现断线重连与幂等回放。
- Store 通过参数注入 `api`、`storage`、`EventSourceImpl` 等依赖，便于单元测试替换为内存实现或 mock。
- 领域事件按 `sequence` 去重后存入 `Map`，并以 `chongming.review.last-sequence.<reviewId>` 前缀持久化到 localStorage，用于同页内重连恢复。
- 视图与组件通过 `props` 传递路由参数（如 `:reviewId`），路由配置中显式声明 `props: true`，避免在组件内直接读取 route。
- 服务层文件与其同名 `.test.js` 单元测试并列放置（如 `review-sse.js` 与 `review-sse.test.js`），遵循单一职责拆分与可测试性约定。
