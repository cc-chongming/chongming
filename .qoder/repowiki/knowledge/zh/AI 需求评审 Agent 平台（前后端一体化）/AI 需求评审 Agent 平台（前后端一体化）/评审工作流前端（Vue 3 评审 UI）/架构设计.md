独立 Vue 3/Vite 应用，入口 `src/main.js` 挂载 `App.vue`，使用 `vue-router` 的 HashHistory 以兼容 Spring Boot 静态资源托管。目录按职责分层：`views/` 承载路由级页面（Dashboard、Requirement*、Review*、Report*），`components/` 提供可复用 UI（对话面板、证据抽屉、辩论时间线、安全 Markdown 渲染等），`stores/review-store.js` 是核心状态管理器，封装 per-review 的领域事件合并、AG-UI 会话适配、SSE 订阅生命周期以及 summary/plans/debates/claims/human-gate/report 等数据的增量刷新；`services/` 提供基础设施抽象：`review-sse.js` 维护每个 review 的可恢复 SSE 连接（指数退避重试、afterSequence 游标），`ag-ui-review-adapter.js`、`runtime-conversation-adapter.js`、`live-run-status.js`、`scout-preview-sse.js`、`safe-markdown.js`、`review-live-presenter.js`、`review-conclusion-presenter.js` 分别对接 AG-UI 协议、运行时状态、SSE 预览与安全渲染；`api/review-api.js` 是薄 REST 客户端，统一错误为 `ReviewApiError`，支持分页拉取 plans、表单上传启动评审、幂等键与 traceId 透传；`composables/use-repository-options.js` 暴露仓库选项组合式函数供组件复用。依赖方向单向：views → components/stores/services → api，stores 通过注入 `api`、`storage`、`EventSourceImpl` 实现可测试性。
