仓库采用前后端分离 + 领域驱动的分层架构：后端 src/ 下 ai.cc.chongming.review 包按 api→application→domain→infrastructure 四层解耦，domain/repository 定义仓储接口并由 infrastructure/persistence（MyBatis）与 InMemory* 实现双写切换；infrastructure/agentscope 将 DebateTools、EvidenceTools、ReadOnlyRepositoryTools 等工具绑定到 AgentScope Harness，承载 Director→四核心角色→冲突检测→约束辩论→Judge Gate→人工决策的编排流。frontend/ 是独立 Vue 3/Vite 应用，通过 REST API 与 SSE 订阅评审事件，并遵循 AG-UI 前端对话契约。docs/ 下 AIREVIEW-PLAN-001~024 为跨子系统的实施基线，每个 PLAN 明确子系统边界与验收证据，作为前后端与文档三方对齐的统一契约。
