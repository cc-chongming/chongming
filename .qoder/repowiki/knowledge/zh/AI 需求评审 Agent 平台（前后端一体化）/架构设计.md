项目采用分层架构：api（REST 控制器）→ application（应用服务）→ domain（领域模型与协议）→ infrastructure（基础设施实现），domain 层不依赖 infrastructure；infrastructure/agentscope/ 作为桥梁将 DebateTools、EvidenceTools、ReadOnlyRepositoryTools 等工具绑定到 AgentScope Harness，使领域逻辑与 AgentScope 框架解耦。运行时通过配置在 infrastructure/persistence/ 的 MyBatis 实现与 InMemory* 实现之间切换仓储模式，支撑单元测试与集成测试双写。application 层聚合审查生命周期、查询、Context Scout/快照等能力，作为 REST API 到领域与运行时的统一编排入口；通知 Outbox 重试与投递服务基于最终 Gate 决策生成幂等命令并持久化，驱动 Review 状态机完成。frontend/ 是独立 Vue 3/Vite 应用，通过 npm run build 产出到 src/main/resources/static/review/，经 REST 与 SSE 与后端通信，遵循 AG-UI 前端对话契约。docs/ 下 24 个 AIREVIEW-PLAN 文档按子系统拆分实现计划，每个文档带有明确边界注释，作为跨子模块的交付契约约束。
