- 领域快照使用 Java record 定义不可变数据载体（如 `ReviewReport`、`ReportContent`、各 `*View`），并在构造块中集中做非空与范围校验。
- 应用服务通过多个仓储/查询接口（`ReviewReportStore`、`HumanReviewItemStore`、`HumanGateDecisionStore`、`ReviewQueryService`）以只读方式聚合事实，不在服务内维护可变状态。
- 报告版本采用递增长整型 `reportVersion`，由 `reportStore.findLatest` 推导新版本号并写入，配合 `gateVersion` 与 `contentHash` 共同标识唯一快照。
- Markdown 渲染统一通过 `StringBuilder` 拼接并以 `# 标题` 分段，证据引用统一通过 `appendEvidenceReferences` 生成相对 URL 形式的 Markdown 链接。
- 对外视图对象（`ReportVersionView`、`RoleView`、`HumanGateView` 等）均为轻量 record，仅用于 API 响应或内部传递，避免直接暴露领域实体。
