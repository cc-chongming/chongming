本模块位于 application 层，对外暴露两个独立的 SSE 注册中心：
- `ReviewSseRegistry`：实现 `ReviewEventListener`，通过 `ConcurrentHashMap<ReviewId, Map<UUID, Subscription>>` 按 Review 维度管理订阅；采用「缓冲→回放→激活」三阶段协议（`subscribe`→`replay`→`activate`）消除注册与历史查询之间的竞态，并通过 `sequence` 去重保证事件顺序；内置固定间隔心跳（`@Scheduled`）和 `SseMetrics` 指标。
- `ReviewRuntimeTraceRegistry`：以 `runtimeId`（正则匹配 `review-{uuid}-attempt-{n}`）为单位维护有界事件环形缓冲区（默认 1000 条），使用虚拟线程池分别处理事件发射与持久化；当 `RuntimeTraceStore` 可用时，对主 runtime 做 best-effort 持久化并在重启后懒加载恢复（`hydrate`），辅助 runtime 不持久化；通过 `deriveEventId` 为不同 AguiEvent 类型生成稳定去重键。
- `ReviewSseProperties` / `ReviewRuntimeTraceProperties` 通过 `@ConfigurationProperties` 注入超时、心跳间隔、批次大小等参数，并提供构造期校验。
依赖方向：application → domain（`ReviewEvent`、`ReviewId`、`AguiEvent`、`RuntimeTraceStore`），不反向依赖 infrastructure。
