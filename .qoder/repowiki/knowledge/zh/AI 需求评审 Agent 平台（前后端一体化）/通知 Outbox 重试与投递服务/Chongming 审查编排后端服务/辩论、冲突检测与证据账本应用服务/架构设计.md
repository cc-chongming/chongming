本模块位于 application 层，围绕 Review 聚合（domain.model.Review）编排四个协作服务：
- ConflictDetectionService：从 ReviewDebateStore 与 ReviewAssessmentStore 批量读取 Claims/Assessments，委托 domain.debate.ConflictDetector 执行确定性规则，维护按 reviewId 分片的 in-memory 审计轨迹（CONFLICT_DETECTION→REGISTERED/SKIPPED），并产出 DebateMetrics 供报告消费。
- DebateService：封装 registerTopics / submitChallenge / submitRebuttal / changePosition / requestAdditionalEvidence / beginSecondRound / beginJudging / skipDebateWhenNoConflicts / closeTopic 等用例，通过 DebateStateMachine 校验回合与状态迁移，使用 ReviewProtocolGuard 限制 Director 可操作范围；所有写操作经 Review.recordCommand 记录 idempotencyKey 以实现幂等重放，并通过 ReviewEventPublisher 发布 ReviewEventType 事件。
- EvidenceLedgerService：基于冻结的 RepositorySnapshot 对单行源码创建/去重 EvidenceBlock，按 reviewId 维护内存 Ledger，提供 submit、findByIds、validateAll 批量验证，路径解析时拒绝符号链接、reparse point、敏感文件名与二进制文件。
- JudgeService：接受 JudgeSubmission 保存 JudgeDecision，并在 JUDGING/WAITING_HUMAN 阶段调用 GatePolicy.draft 生成 AI Gate 草稿，同时根据 RolePackRegistry 推导 requiredCheckpointSet 作为正覆盖检查输入。
依赖方向单向向下：application → domain.repository（ReviewDebateStore、ReviewAssessmentStore）、domain.protocol/state-machine、domain.gate；不反向依赖 infrastructure，基础设施通过 Spring @Autowired 注入具体实现。
