- 领域模型统一使用 Java record 并在构造块中执行非空与取值范围校验，失败时抛出 IllegalArgumentException。
- 状态变更通过不可变的 copy/new 方法配合乐观锁 version 字段进行，所有写操作前调用 requireVersion 校验版本。
- 对外部依赖采用接口隔离：通知传输通过 `NotificationDeliveryPort` 抽象，仓储通过 `*Store` 接口，便于替换 InMemory/MyBatis 实现。
- 关键业务动作完成后通过 `eventPublisher.publish(ReviewEventDrafts.completedCommand(...))` 发布领域事件，并将角色固定为 RoleType.DIRECTOR。
- 幂等性通过 `idempotencyKey()` 结合 `outboxStore.findByIdempotencyKey` 在 enqueue 阶段去重，避免重复投递同一 Gate 结果。
- 控制器端点先通过 `ReviewerIdentityProvider.currentReviewer().canReview()` 校验权限，再委托应用服务执行写操作。
