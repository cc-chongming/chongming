本模块按分层架构组织：api 子包中的控制器仅做参数校验与路由转发，application 子包中的各 Service 是跨用例的编排中心，domain/model 提供 Review、SnapshotReference、SharedRepositorySnapshot 等共享实体，infrastructure 提供仓储与 AgentScope 适配。
- 编排职责划分：ReviewIntakeService/ReviewOrchestrationService/ReviewLifecycleService/ReviewRecoveryService 构成主流程编排；DashboardQueryService/InitialReviewProgressService/ReviewListQueryService/ReviewQueryService 负责只读查询与角色守卫推进；ContextScoutPreviewService/ContextScoutConclusionService/RepositorySnapshotService/SharedSnapshotLifecycleService 封装 Context Scout 与仓库快照能力；ReviewEventService 暴露事件总线；ReviewRuntimeContext/ReviewContextAssembler 在编排过程中组装并传递运行时上下文。
- 通过 domain 协议（如 ReviewTypes、领域工具接口）解耦 application 与 infrastructure，仓储实现可在 MyBatis 与 InMemory* 之间切换，使同一编排逻辑同时支持内存与 MySQL 模式。
- 角色编排遵循 Director→四核心角色 Claim→冲突检测→约束辩论→Judge Gate 草稿→人工决策的主线，可选角色按需激活，由 RoleActivationService 与上述编排服务协同完成。
