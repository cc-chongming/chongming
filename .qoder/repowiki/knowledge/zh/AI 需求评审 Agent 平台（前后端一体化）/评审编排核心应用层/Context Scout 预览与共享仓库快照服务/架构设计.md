本模块位于 application 层，由四个 Spring @Service 组成，职责按“运行态”与“存储态”分离：
- ContextScoutPreviewService：基于 ContextScoutHarnessFactory 启动与正式 Review 隔离的浏览器预览 Agent，使用 ConcurrentMap 维护 PreviewRun 生命周期（QUEUED/RUNNING/COMPLETED/FAILED），通过 ReviewRuntimeTraceRegistry 发布 AG-UI 事件流，并用 RuntimeTraceRedactor 脱敏错误；结果经 ReviewAgUiEventMapper 映射后写入 trace，可见文本通过 scoutFactory.recordPreviewResult 落盘。
- ContextScoutConclusionService：对 Scout 输出的公开 JSON 进行宽松解析（失败时回退为截断摘要），以 @Transactional 事务调用 ContextScoutConclusionStore 持久化，封装 schema version 与字段抽取逻辑。
- RepositorySnapshotService：核心快照引擎，通过 RepositoryBoundaryGuard 校验仓库白名单，用 GitSnapshotReader 读取 HEAD/Branch/Dirty 状态，计算 snapshotKey = sha256(repositoryId + headCommit + worktreeFingerprint) 实现内容寻址；在 stagingDirectory 中复制文件并生成 repository-files.ndjson 清单，再以原子 move 发布到 workspaceRoot/repository-snapshots/{sha256(repoId)}/{snapshotKey}，并通过 reviews/{reviewId}/attempts/{attemptNo}/snapshot-reference.json 建立引用；提供 cleanupUnreferencedSnapshots 按 retention 清理无引用快照。
- SharedSnapshotLifecycleService：@Scheduled 定时任务，周期性调用 RepositorySnapshotService 清理过期共享快照。
依赖方向：application → domain（Review、RepositorySnapshot、ContextScoutConclusion、各 Store/Registry 接口）+ infrastructure.agentscope（Harness、WorkspaceLayout、Trace、AgUiEventMapper）+ infrastructure.repository（GitSnapshotReader、RepositoryBoundaryGuard），不反向依赖基础设施具体实现。
