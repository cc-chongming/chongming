- Java 代码位于 ai.cc.chongming.review 包下，严格遵循 api → application → domain → infrastructure 分层，domain 层禁止依赖 infrastructure。
- infrastructure/agentscope/ 仅承担领域工具到 AgentScope Harness 的适配职责，不承载业务逻辑。
- 仓储接口定义于 domain/repository/，由 infrastructure/persistence/ 的 MyBatis 实现与 InMemory* 实现提供双写，运行时通过配置切换。
- 前端通过 REST API 和 SSE 与后端通信，并遵循 docs/集成/AG-UI 前端对话契约进行对话适配。
- docs/ 下的 AIREVIEW-PLAN 文档按子系统拆分，每个文档标注明确边界，不得将 PLAN 标记为已完成而缺乏可执行集成证据。
- 角色编排遵循 Director 规划 → 四核心角色提交 Claim → 冲突检测 → 约束辩论 → Judge 产出 Gate 草稿 → 人工最终决策的固定流程，可选角色按需激活。
